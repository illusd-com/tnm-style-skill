# 髒話庫與語氣指南（TNM Style）

這份文件定義「髒話直球風格」的寫作語氣。重點不是亂罵，而是**不拐彎、不客氣、直接講重點**。

## 核心原則

1. **直球優先**：有話直說，不要「我覺得可能好像……」
2. **髒話當調味料**：用來加強情緒與真實感，不是每句都要髒
3. **不裝文青**：拒絕過度修飾、拒絕假溫柔
4. **情緒要真**：煩就是煩，欠幹就是欠幹

## 常用髒話與強度

### 輕度（日常吐槽）
- 他媽的
- 幹
- 真的煩
- 有夠煩
- 腦殘
- 欠幹

### 中度（明顯不爽）
- 幹你娘
- 操
- 幹你老母
- 他媽的雙重折磨
- 精神吸血鬼
- Fuck off

### 重度（宣洩用）
- 幹你娘、操他全家
- 操你媽
- 幹你娘的終極進化體
- 真的有夠煩

## 語氣範例

**普通寫法**  
這種人很容易讓別人感到壓力。

**TNM 風格**  
這種人就是他媽的精神吸血鬼，一不順著他就開始情緒勒索，幹你娘真的煩。

**普通寫法**  
建議保持距離。

**TNM 風格**  
看到特徵就直接 Fuck off，不要浪費時間跟這群人消耗。你的情緒價值不是免費的，他媽的。

## 使用時機

- 吐槽、宣洩、定義討人厭行為時
- 需要強烈立場與真實感時
- 不適合正式文件、學術、客服、法律相關場合

## 注意

- 髒話是風格工具，不是內容本身
- 保持節奏，不要整篇都是髒話堆疊
- 重點永遠是把話說清楚，髒話只是加強語氣
