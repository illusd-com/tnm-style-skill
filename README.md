# tnm-style-skill

**TNM Style Skill** — 新細明體 + 髒話直球風格的 CSS 與寫作規範

從網站提煉的純風格資源，已過濾所有主題內容，只保留視覺與語氣規範。

## 內容

| 檔案 | 說明 |
|------|------|
| `SKILL.md` | Agent 技能說明（觸發條件與使用方式） |
| `skill.md` | 同上（小寫別名） |
| `assets/tnm-style.css` | 完整可用的 CSS |
| `references/swear-library.md` | 髒話庫與語氣指南 |
| `references/style-guide.md` | 版面與字體細節 |

## 快速使用

```html
<link rel="stylesheet" href="assets/tnm-style.css">
```

或直接複製 `assets/tnm-style.css` 內容。

## 核心特徵

- **字體**：新細明體（PMingLiU / 新細明體）優先
- **背景**：純白 `#ffffff`
- **按鈕**：黑底白字，圓角小、hover 變深
- **語氣**：直球、髒話多、不拐彎抹角
- **版面**：置中、乾淨、section 清楚分隔
